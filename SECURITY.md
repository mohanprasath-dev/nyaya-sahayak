# Security Policy

Nyaya Sahayak is built with a zero-trust, privacy-first architecture designed specifically for sensitive legal assistance contexts.

---

## 1. Threat Model & Security Commitments

| Threat Vector | Mitigation Strategy | Verification |
|---|---|---|
| **Data Leakage / PII Storage** | Completely stateless backend. Zero persistent databases, zero cookies, zero local storage of legal narratives. | Codebase inspection & static analysis |
| **API Denial of Service / Abuse** | In-memory sliding-window IP rate limiter across all 4 API routes (`429 Too Many Requests`). | Automated integration tests (`vitest`) |
| **Prompt Injection / Jailbreaks** | Strict input sanitization, max character bounds (4,000 chars), and deterministic statutory grounding. | Automated test suite & prompt guardrails |
| **Cross-Site Scripting (XSS)** | Strict Content Security Policy (`CSP`), `X-Content-Type-Options: nosniff`. | Header assertions in `next.config.ts` |
| **Clickjacking** | `X-Frame-Options: DENY` on all responses. | Header assertions in `next.config.ts` |
| **Secret Exposure** | `GEMINI_API_KEY` is loaded strictly server-side in API route handlers; never embedded into client bundle. | Git history & bundle inspection |

---

## 2. HTTP Security Headers

Every HTTP response generated by the application is enforced with the following security headers in `next.config.ts`:

- `Content-Security-Policy`: Restricts scripts, frames, and connections to trusted origins.
- `Strict-Transport-Security`: `max-age=63072000; includeSubDomains; preload` (enforces modern TLS).
- `X-Frame-Options`: `DENY` (blocks embedding in malicious iframes).
- `X-Content-Type-Options`: `nosniff` (prevents MIME-type sniffing).
- `Referrer-Policy`: `strict-origin-when-cross-origin`.
- `Permissions-Policy`: `camera=(), microphone=(), geolocation=()`.

## 3. Rate Limiting Architecture

All API endpoints implement client IP rate limiting:
- `/api/assist`: 15 requests per minute per IP.
- `/api/analyze-document`: 15 requests per minute per IP.
- `/api/compare-documents`: 15 requests per minute per IP.
- `/api/document-qa`: 15 requests per minute per IP.

Rate limit headers returned on each request:
- `X-RateLimit-Limit`: Maximum allowable requests per sliding window.
- `X-RateLimit-Remaining`: Count of remaining attempts in current window.
- `Retry-After`: Seconds to wait when threshold is exceeded.
