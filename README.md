# Nyaya Sahayak (Women's Legal Safety & Rights Assistant)

Nyaya Sahayak is a guided, privacy-first legal safety assistant for women in India. It pairs a deterministic rule engine (mapping incidents to POSH Act 2013, PWDVA 2005, IT Act 2000, and Bharatiya Nyaya Sanhita 2023 / IPC provisions) with Google Gemini AI to generate plain-language guidance and structured draft complaints.

Built for the HackToSkill x Google "AI for Legal Assistance & Access" challenge.

## Quick Start

```bash
# Install dependencies
npm install

# Copy environment variables template
cp .env.example .env.local
# Add your GEMINI_API_KEY from https://aistudio.google.com

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Legal Disclaimer

Nyaya Sahayak provides self-help legal information and procedural guidance. It is NOT a substitute for professional legal advice or emergency services. In cases of immediate danger, please call **112** (All-India Emergency) or **181** (Women Helpline).
